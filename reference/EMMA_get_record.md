# EMMA_get_record

EMMA_get_record

## Usage

``` r
EMMA_get_record(res)
```

## Arguments

- res:

  Functional Enrichment Analysis results (enrichResult, gseaResult ...)
  generated by [`EMMA_run()`](EMMA_run.md)

## Value

list of metadata recorded during FEA runtime
